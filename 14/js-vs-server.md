De server-side validatie blijft nodig, omdat de HTML- en JavaScript-kant op zichzelf niet voldoet.
De gebruiker kan namelijk simpelweg de HTML openen en deze JavaScript-validatie uit de HTML verwijderen.
Dat zorgt ervoor dat het formulier op een foutieve manier ingevuld kan worden.
De backend-validatie is daarentegen niet zo makkelijk te omzeilen.
